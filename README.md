Leonida Trophy Guide — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy is shown with its official name, description and grade, a guide written for this page that cites its sources, a roadmap to the platinum in four stages, a flag for the one possibly missable trophy, and a checklist that saves in your browser with export and import. Filters cover story, side quests, collectibles, activities, free-roam and online (there are no online trophies), and a spoiler setting hides hidden story trophies until you earn them. The app is plain static files under `app/` — no build step, no network requests — and `main.ts` hands it in with a dossier for the make.fun judge.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. To take it offline, serve `app/` with any static file server, or open `app/index.html` after starting one — the page loads nothing from the network.
